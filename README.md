# 🥋 AI Martial Arts Trainer

An AI-powered karate training platform that uses real-time pose detection to classify techniques, display animated 3D skeleton references, and deliver personalized coaching feedback via a RAG pipeline.

---

## 🆕 What Was Added (Safwat_branch — RAG + Auto-Trigger Session)

### RAG Coaching System
The backend now includes a full **Retrieval-Augmented Generation (RAG)** coaching pipeline:

| File | Role |
|---|---|
| `backend/app/rag/angle_calculator.py` | Computes 14 joint angles (degrees) from 33 MediaPipe landmarks |
| `backend/app/rag/dtw_comparator.py` | **DTW** — aligns user's 30-frame rep to Exemplar reference frame-by-frame, finds worst joints |
| `backend/app/rag/pipeline.py` | Orchestrates: landmarks → DTW → ChromaDB → Groq → coaching text |
| `backend/app/rag/retriever.py` | ChromaDB vector search for coaching knowledge chunks |
| `backend/app/rag/llm_client.py` | Groq API (Llama-3.3-70b) generates friendly coaching feedback |
| `backend/app/rag/data/coaching_chunks.json` | 28 hand-written coaching tips per move/joint |
| `backend/app/rag/data/exampler_sequences.json` | ← **generated by script** (see below) |
| `backend/app/routers/rag_feedback.py` | `POST /api/rag/feedback` and `POST /api/rag/chat` endpoints |

### How RAG coaching works (end-to-end)
```
User does a rep (30+ frames captured automatically)
        ↓
Frontend sends 30 raw landmark frames to POST /api/rag/feedback
        ↓
Backend: compute 14 angles per frame (degrees) → shape (30, 14)
        ↓
DTW aligns user sequence to Exemplar reference sequence frame-by-frame
        ↓
Joints with mean deviation > 12° are flagged (e.g. "left_knee off by 28°")
        ↓
Error descriptions queried in ChromaDB (sentence-transformer embeddings)
        ↓
Groq Llama-3.3 generates friendly coaching text from matched knowledge chunks
        ↓
Result displayed in "🤖 AI Sensei" panel on the Train page
```

> **Important distinction**: the old teammate code compared a user's single frame to *statistical averages* (mean ± std) of the full Exemplar video. This version captures the user's full 30-frame rep and aligns it to the Exemplar rep **second-by-second using DTW**, which gives much more accurate frame-level feedback.

### Auto-trigger smart capture
The "Record Rep" button was replaced with an **"Arm Rep"** system:

```
User clicks "🥋 Arm Rep"
    ↓
System enters ARMED state (🟡 yellow overlay)
    ↓   ← user can reposition, walk into frame, take up to 10 seconds
Motion energy spike detected for 2+ consecutive frames (threshold = 0.35)
    ↓
System AUTO-triggers capture (🔴 red overlay)
    ↓
Collects 45 post-trigger frames
    ↓
findBestWindow() searches:
  [150-frame pre-buffer] + [45 post-trigger frames] = 195 frames total
  → picks the 30 frames with highest joint-angle movement
    ↓
Best 30 frames → Bi-LSTM classifier + DTW/RAG coaching
```

> **Threshold note**: `ENERGY_THRESHOLD = 0.35` (in `train/page.js`) is calibrated for 0–1 normalized angles.  
> Open browser DevTools → Console to see `[AutoTrigger] energy=X.XXX` lines while armed.  
> Raise the value if it triggers too easily; lower it if it never fires.

### 3D Skeleton Preview + Videos (unchanged from previous session)
- `MoveSkeletonPreview.js` renders pre-extracted MediaPipe landmarks as front/side animated canvas
- Backend streams `.mov` files with HTTP Range request support

## 2. Backend Setup

### Prerequisites
- **Python 3.12** (tested on 3.12.7)
- `cvEnv` virtual environment in `../cvEnv/`

### Activate & install

```powershell
# Windows PowerShell — from project root
..\cvEnv\Scripts\activate
pip install -r backend/requirements.txt
```

### Configure environment

Create `backend/.env` (gitignored):

```env
DATABASE_URL=sqlite:///./martial_arts.db
SECRET_KEY=your-secret-key-change-this
FRONTEND_URL=http://localhost:3000
GROQ_API_KEY=<your-groq-api-key>   ← get free key at console.groq.com
```

### One-time RAG setup scripts

Run these **once** (from `backend/` with cvEnv active):

```powershell
cd backend

# Step 1 — extract per-frame angle sequences from Exemplar videos
# Requires: Examplers/*.mp4 to exist in app/data/Examplers/
# Output:   app/rag/data/exampler_sequences.json
python scripts/extract_exampler_sequences.py

# Step 2 — index coaching knowledge into ChromaDB (vector DB)
# Input:    app/rag/data/coaching_chunks.json (already committed)
# Output:   app/rag/data/chroma_db/  (local, gitignored)
python scripts/seed_chroma.py
```

### Start backend

```powershell
cd backend
uvicorn app.main:app --reload
```

**Backend:** `http://localhost:8000`  
**Swagger docs:** `http://localhost:8000/docs`

## 5. How to Test the Full Pipeline

1. Open `http://localhost:3000` and **register/login**
2. Go to **Train** page (`/train`)
3. Upload a karate video (`📁 Upload Video`) or start camera (`📹 Start Camera`)
4. **Select a specific move** from the dropdown (not "Free Practice")
5. Click **▶ Start Session**
6. Click **🥋 Arm Rep 1**
7. The overlay turns **🟡 yellow** — the system is now watching for motion
8. Perform the technique — the overlay turns **🔴 red** automatically when motion is detected
9. After capture completes:
   - **Classification result** appears (which move, confidence %)
   - **🤖 AI Sensei** panel shows coaching feedback from Groq
10. Open browser **DevTools → Console** to see `[AutoTrigger] energy=X.XXX` (useful for threshold debugging)
11. Open the **🤖 chatbot** (bottom-right) and ask questions — it uses the same Groq RAG backend

### Testing the RAG API directly (Swagger)

## 7. Key API Endpoints

| Method | URL | Description |
|---|---|---|
| `GET` | `/health` | Backend health check |
| `POST` | `/api/classify` | Submit 30 frames → Bi-LSTM classification |
| `GET` | `/api/video/{move}/{view}` | Stream reference video (Range requests) |
| `GET` | `/api/video/{move}/landmarks?view=front` | Pre-extracted JSON landmarks |
| `POST` | `/api/rag/feedback` | 30 landmark frames → DTW → Groq coaching |
| `POST` | `/api/rag/chat` | Free-text question → RAG → Groq answer |

## 8. Troubleshooting

| Problem | Fix |
|---|---|
| Armed overlay times out, no trigger | Open DevTools console — check `[AutoTrigger] energy` values. If always 0, MediaPipe is not detecting pose (check video visibility). If low (< 0.2), lower `ENERGY_THRESHOLD` in `train/page.js` |
| RAG returns no feedback | Run `python scripts/seed_chroma.py` and `python scripts/extract_exampler_sequences.py` first |
| `ValueError: collection not found` | ChromaDB not seeded — run `seed_chroma.py` |
| `GROQ_API_KEY missing` | Add `GROQ_API_KEY=...` to `backend/.env` |
| `uvicorn not found` | Activate `cvEnv` first |
| Video shows "not found" | Check `.mov` files are in `backend/app/data/Animation/` |
| `AxiosError: Network Error` | Backend is not running |
| Camera won't start | Allow camera permission in browser for `localhost:3000` |
