# 🥋 AI Martial Arts Trainer

An AI-powered karate training platform that uses real-time pose detection to classify techniques and display animated 3D skeleton references extracted from master-level demonstration videos.

---

## 2. Backend Setup (Python 3.12 / FastAPI)

### Prerequisites
- **Python 3.12** (tested on 3.12.7)
- **Conda** environment named `cvEnv` (recommended) **or** a standard virtualenv

### Activate the environment

```powershell
# From the project root (Windows — Anaconda Prompt or PowerShell):
..\cvEnv\Scripts\activate

# macOS / Linux:
conda activate cvEnv
# or
source ../cvEnv/bin/activate
```

### Install Python dependencies

```bash
pip install -r backend/requirements.txt
```

### Configure environment

```bash
# backend/.env  (create this file — it is gitignored)
DATABASE_URL=sqlite:///./martial_arts.db
SECRET_KEY=your-secret-key-change-this
ALGORITHM=HS256
```

### Run migrations & start server

```bash
cd backend
alembic upgrade head          # initialise the DB (first time only)
uvicorn app.main:app --reload
```

**Backend:** `http://localhost:8000`  
**Swagger docs:** `http://localhost:8000/docs`

---

## 3. Frontend Setup (Next.js 16 / Node.js)

### Prerequisites
- **Node.js** v18 LTS or higher
- **npm** (comes with Node)

### Install & run

```bash
cd frontend
npm install
npm run dev
```

**Frontend:** `http://localhost:3000`

### Environment (optional — defaults work for local dev)

```bash
# frontend/.env.local  (create if you need to change the API URL)
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## 6. Key API Endpoints

| Method | URL | Description |
|---|---|---|
| `GET` | `/health` | Backend health check |
| `POST` | `/api/classify` | Submit 30 frames → get move classification |
| `GET` | `/api/video/{move}/{view}` | Stream reference video (HTTP Range supported) |
| `GET` | `/api/video/{move}/landmarks?view=front` | Get pre-extracted JSON landmarks |
| `GET` | `/api/video/info` | List all available moves and files |

**Move name values:** `mae_geri` · `gyaku_zuki` · `gedan_barai`  
**View values:** `front` · `side`

## 7. Re-extracting Landmarks (if you add new videos)

```bash
# From project root with cvEnv active:
cd backend
python scripts/extract_landmarks.py
```

This scans `app/data/Animation/` and generates a `.json` file next to each `.mov`. Skip files that already have a `.json`.

## 8. Troubleshooting

| Problem | Fix |
|---|---|
| `uvicorn not found` | Make sure `cvEnv` is activated before running |
| Video shows "not found" | Check that `.mov` files are in `backend/app/data/Animation/` |
| AI Preview shows "no data" | Backend must be running **and** `.json` files must exist next to the `.mov` |
| `AxiosError: Network Error` | Backend is not running — start `uvicorn app.main:app --reload` |
| Camera won't start | Allow camera permission in the browser for `localhost:3000` |
| Port conflict | Backend: `uvicorn app.main:app --reload --port 8001` · Frontend: `npm run dev -- -p 3001` |
